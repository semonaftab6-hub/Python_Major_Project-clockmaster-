## 🌟 About The Project

**CLOCK MASTER** is a Python-based time management application developed using **Jupyter Notebook**. It combines essential clock utilities with smart study planning and productivity tracking features.

The application provides a simple, menu-driven interface that allows users to access multiple time management tools in one place.

💡 **Our Goal:** To make everyday time management easier while encouraging better study planning and productivity.

---

## ✨ Key Features

### 🕒 1. Digital Clock
- Displays the current date and time.
- Updates every second.
- Supports a 12-hour format with AM/PM.
- Can be stopped using `Ctrl + C`.

### ⏰ 2. Alarm Clock
- Set an alarm using the 24-hour format (`HH:MM`).
- Continuously checks the current time while the alarm function is running.
- Displays an alarm notification when the scheduled time is reached.
- Supports alarm cancellation using `Ctrl + C`.
- Validates the entered time format.

### ⏱️ 3. Stopwatch
- Measures elapsed time.
- Supports lap recording through user input.
- Displays minutes, seconds, and milliseconds.
- Uses `S` to stop the stopwatch.
- Supports cancellation using `Ctrl + C`.

### ⏳ 4. Countdown Timer
- Set a countdown duration in minutes.
- Displays the remaining time.
- Shows a completion message.
- Supports cancellation using `Ctrl + C`.

### 📚 5. Smart Study Planner
<kbd>⭐ UNIQUE FEATURE</kbd>

- Enter a subject and topic.
- Set a preferred study duration.
- Start a focused study session.
- Automatically saves successfully completed sessions.
- Does not save cancelled sessions.

### 📖 6. Study History
- View previously completed study sessions.
- Display subject and topic details.
- Check study duration and date.
- Shows a message when no records are available.

### 📊 7. Productivity Statistics
<kbd>⭐ UNIQUE FEATURE</kbd>

- Displays total completed study sessions.
- Calculates total study time in minutes.
- Displays total study hours.

### 📅 8. Daily Productivity Summary
- Displays the current date.
- Shows today's completed study sessions.
- Calculates total study time for the day.

## ⚠️ Current Limitations

- Alarm monitoring works only while the Alarm Clock function is running.
- Background alarm monitoring is not supported.
- Only one alarm can be monitored at a time.
- Stopwatch lap recording depends on user input; it does not show a continuously updating display.
- Study records are stored temporarily in memory.
- Data is reset when the Jupyter Notebook kernel restarts.
- The application currently uses a menu-driven interface instead of a graphical interface.
